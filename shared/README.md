# shared

Package `ag_shared` (created in task 1.1): code imported by both the server
and the workstation. No framework or hardware imports.

Planned contents: `AttentionState` and other enums, config models
(`Thresholds`, `PpeProfile`, `CameraConfig`, `EngineConfig`, `SiteSettings`),
API payload models for `docs/api-contract.md`, the string catalog loader and
the message catalogs.
